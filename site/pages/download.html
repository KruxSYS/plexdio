Windows SmartScreen

Plexdio's files are not code-signed, so Windows may show “Windows protected your PC” the first time you run the installer or plexdio.exe. Check the SHA-256 above, then choose More info → Run anyway.

Requirements

Windows 10 or 11, 64-bit, a Plex account and a Plex Media Server with a music library. Plexdio is in development: it has been tested against a mock Plex server only. See the docs for installing, updating and where your data lives.
