Install

Get Plexdio from the download page. You need Windows 10 or 11 on a 64-bit (x64) PC.

  • Installer (Plexdio-<version>-win-x64-setup.exe): run it and follow the steps. It installs for your Windows user only, into %LOCALAPPDATA%\Programs\Plexdio, and needs no administrator rights. Started as an administrator, it also offers to install for all users (into Program Files). It adds a Start menu shortcut, an optional desktop shortcut and an entry in Settings → Apps.
  • Portable zip (Plexdio-<version>-win-x64-portable.zip): unzip it anywhere (a folder in your documents, a USB stick) and start Plexdio\plexdio.exe.

The files are not code-signed. If Windows shows “Windows protected your PC”, compare the file's SHA-256 with the one on the download page (PowerShell: Get-FileHash .\file -Algorithm SHA256), then choose More info → Run anyway.

Settings → About shows which kind of copy is running (Installed, Portable, or Standalone exe for a bare plexdio.exe from an older download, which uses your Windows profile like an installed copy).

First sign-in

  1. Start Plexdio and choose Sign in with Plex. Your browser opens plex.tv with a code that is also shown in the app. Sign in there and allow the app; your password never goes through Plexdio.
  2. Pick a server and a music library. Plexdio tries every address of the server and uses the best one (local, then remote, then relay).
  3. The first sync copies the library into a local cache. After that, Plexdio opens the cached library at once and syncs changes in the background.

The Plex sign-in is stored in the Windows Credential Manager (as “Plexdio”), never in a settings file. Sign out in Settings → Account removes it.

Updates

Plexdio checks this website for a new version a few seconds after it starts and then at most once a day. When there is one, a notice appears above the page and in Settings → About, with a link to the release notes.

  • Update now in an installed copy downloads the new installer, checks its SHA-256 against the update information, runs it silently and starts the new version. Your settings stay where they are.
  • Update now in a portable copy downloads the new zip, checks its SHA-256, replaces plexdio.exe and restarts. Data\ is not touched. If the folder is read-only, Plexdio offers the download page instead.
  • A download that does not match its SHA-256 is deleted and nothing is installed.

Check for updates in Settings → About checks at once; Automatically check for updates turns the daily check off. The Beta channel also offers preview versions. What the check sends is described on the privacy page. If the check fails (no internet), nothing else is affected.

To back up, quit Plexdio (tray icon → Quit) and copy %APPDATA%\Plexdio (settings) and, if you want your play history, Ride scores and downloads too, %LOCALAPPDATA%\Plexdio\db and %LOCALAPPDATA%\Plexdio\offline. A portable copy is backed up by copying its whole folder. Everything else in the cache is downloaded again when needed. The sign-in is not part of a backup: just sign in again.

Uninstall

  • Installed: Settings → Apps → Installed apps → Plexdio → Uninstall (or Uninstall in the Start menu entry's menu). It removes the program and the start-with-Windows entry and keeps your settings and cache. To remove those too, delete %APPDATA%\Plexdio and %LOCALAPPDATA%\Plexdio, and the “Plexdio” entry in the Credential Manager (or sign out in Plexdio first).
  • Portable: quit Plexdio and delete its folder. If you turned on Start with Windows, turn it off first.

FAQ

Does Plexdio work with Plexamp's features?

It uses your own Plex server's API. Server-side features such as sonic similarity are used where the server offers them; Plexamp-only features are not available.

Has it been tested with a real Plex server?

Not yet. Plexdio has been tested against its own mock Plex server under Wine and on a Windows 11 VM, and real audio output has not been checked. Cast is experimental. Please report what you find.

Can I move a portable copy?

Yes. Quit Plexdio and move the whole folder, including Data\. The sign-in is in the Credential Manager, so it moves with your Windows user, not with the folder.
